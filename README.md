# InternNova Homepage Redesign

A responsive homepage redesign concept for the InternNova website, built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation and accessible mobile menu
- Hero section with custom CSS dashboard illustration
- About, internship domains, learning approach, workshops, learner stories, FAQs, CTA, and footer
- Scroll-reveal animations with reduced-motion support
- Accessible focus states, semantic HTML, skip link, and descriptive links
- No framework or build step required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

For a local development server, you can use VS Code's Live Server extension or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on Netlify

1. Push this folder to a GitHub repository.
2. Sign in to Netlify and choose **Add new site → Import an existing project**.
3. Connect GitHub and select this repository.
4. Because this is a static site, leave the build command blank and set the publish directory to the repository root (`.`).
5. Deploy and test the generated URL on desktop and mobile.

## Publish on GitHub

Create a repository, then upload `index.html`, `style.css`, `script.js`, and this README. Add final screenshots to a `screenshots/` folder after capturing your actual deployed website.

## Before submitting

- Replace sample learner stories with approved, authentic testimonials or remove them.
- Verify any program names, openings, benefits, certificates, duration, and eligibility with InternNova.
- Test every link and the mobile menu.
- Capture full-page and mobile screenshots of the final deployed design.
- Make sure the live website and GitHub repository are accessible to the reviewer.
